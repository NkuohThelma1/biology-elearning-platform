# Biology E-Learning & Academic Assessment Platform

A modern, responsive web-based learning platform designed for secondary school students to study Biology online, take quizzes, track academic performance, and for administrators to manage lessons and assessments.

## 🎓 Project Overview

This platform provides:
- **For Students**: Access to Biology lessons, interactive quizzes, instant results, performance tracking, and academic progress analytics
- **For Administrators**: Lesson management, quiz creation, student management, and comprehensive performance reports

## 🛠️ Tech Stack

### Frontend
- **React.js** - Modern UI library
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **React Router DOM** - Client-side routing
- **Axios** - HTTP client for API requests
- **React Icons** - Professional icon library
- **Recharts** - Data visualization and charts

### Backend
- **Laravel** - PHP web framework
- **MySQL** - Relational database
- **Laravel Sanctum** - API authentication

## 🎨 Design Features

- Clean, professional, student-friendly UI
- Responsive design (desktop, tablet, mobile)
- Color palette: Biology Green (#22C55E), Light Blue (#38BDF8), White, Soft Gray
- Card-based dashboard layout
- Academic and professional appearance
